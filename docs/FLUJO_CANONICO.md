# FLUJO CANÓNICO DE UNA LLAMADA — Vozra PID

> Dictado por sam el 2026-08-09. **Esta es la referencia contra la que se juzga si
> una llamada salió bien.** Las frases son abreviadas: importa el orden y la
> intención, no las palabras exactas.

---

## El flujo, paso a paso

### 1. Bienvenida
Mensaje de saludo. Nada más.

### 2. Qué quiere
El cliente dice a qué llama. Tres caminos:

| Dice | Qué se hace |
|---|---|
| **A domicilio** | Sigue el flujo de pedido |
| **Recoger** | Sigue el flujo de pedido, sin dirección |
| **Otra cosa** (algo que no trabajamos, información específica) | **Se le toman los datos y se avisa al manager, que le llama.** Nunca se le manda a llamar a otro sitio |

### 3. Teléfono
Se le pide el teléfono. Con él, la ficha del cliente tiene que aparecer con:

- Nombre
- Dirección
- **Notas especiales**: alergias, incidencias previas, pedido habitual

### 4. Reconocimiento
Si está registrado, se le reconoce por su nombre: *"Aquí estás, Samuel."*

### 5. La dirección — SIEMPRE SE PREGUNTA, NUNCA SE ASUME

> *"¿Te lo llevo a la dirección de siempre?"*

- **Dice que sí** → se sigue.
- **Dice otra dirección** → se le pide la nueva y se usa esa.

**La ficha del cliente es RECURRENTE entre sesiones pero DINÁMICA, no rígida.**

> "Yo puedo llamar de casa de un amigo o de un familiar, y ese día lo quiero en esa
> dirección especial. Por eso se le pregunta: ¿te la llevo a la de siempre?" — sam

Esto vale para todo el perfil, no solo la dirección: **lo que el cliente dice en
vivo manda sobre lo guardado**, y se persiste cuando proceda.

### 6. El pedido
Con la dirección resuelta, se le pregunta qué va a pedir.

### 7. El resto
Alérgenos (advertir, asesorar, decide el cliente), sugerencia UNA vez, resumen,
confirmación, envío a cocina, despedida.

---

## Lo que NO se hace en ningún paso

- **No se pregunta dos veces lo mismo.** Una pregunta se hace una vez; solo se
  repite si no se ha entendido la respuesta.
- **No se repite el nombre en cada frase.** Al reconocerle y al despedirse, y basta.
- **No se le devuelve un dato que acaba de dar.** Se agradece en dos palabras y se sigue.
- **No se le pregunta por el tipo de entrega** si ya se ha confirmado la dirección.
